---
name: Lean Mode 2026-05-19
description: Feature flag VITE_LEAN_MODE che riduce sidebar a 7 voci e introduce /v2/comms
type: feature
---
Flag in `src/lib/featureFlags.ts` (`LEAN_MODE`, default true). Quando ON, `navItemsDef` in `src/v2/ui/templates/navConfig.tsx` viene filtrato a 7 voci via `LEAN_NAV_PATHS`:
- /v2/command
- /v2/explore/network
- /v2/cockpit
- /v2/comms (Comunicazioni — nuova rotta-guscio Fase 3)
- /v2/agenda
- /v2/intelligence/agents
- /v2/settings

Tutte le altre rotte restano REGISTRATE e raggiungibili via deep-link, popover "Tutte le pagine" e SECONDARY_NAV. Nessuna pagina cancellata. Per spegnere: `VITE_LEAN_MODE=false`.
